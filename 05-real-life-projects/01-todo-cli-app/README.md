# ✅ Todo CLI Application

## 🎯 Project Overview

A command-line todo application with data persistence using JSON.

## 🌟 Features

- ✅ Add new tasks
- 📋 List all tasks
- ✔️ Mark tasks as complete
- 🗑️ Delete tasks
- 💾 Data persistence (JSON file)
- 🎨 Color-coded output

## 🚀 Usage

```bash
python todo.py
```

## 📚 What You'll Learn

- File handling (JSON)
- Command-line interfaces
- Data persistence
- User input validation
- CRUD operations

## 🔧 Technologies

- Python 3.x
- JSON for data storage
- Colorama for colored output (optional)
