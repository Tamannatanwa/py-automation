# 💰 Expense Tracker

## 🎯 Project Overview

Track your expenses and generate reports with this CLI application.

## 🌟 Features

- 💵 Add expenses with categories
- 📊 View expense reports
- 📈 Category-wise analysis
- 📅 Date-range filtering
- 📁 CSV export functionality

## 🚀 Usage

```bash
python expense_tracker.py
```

## 📚 What You'll Learn

- File handling (CSV)
- Data analysis
- Date manipulation
- Report generation
- Data visualization (optional)
