## 📖 What are Variables?

Variables are containers that store data values. Think of them as labeled boxes where you can put information and retrieve it later.

### Real-Life Analogy:
Imagine you have labeled jars in your kitchen:
- A jar labeled "sugar" contains sugar
- A jar labeled "flour" contains flour
- In Python, variables work the same way!

## 🔤 Basic Data Types

Python has several built-in data types:

1. **Integer (int)** - Whole numbers
   - Examples: 5, -10, 1000

2. **Float (float)** - Decimal numbers
   - Examples: 3.14, -0.5, 2.0

3. **String (str)** - Text data
   - Examples: "Hello", 'Python', "123"

4. **Boolean (bool)** - True or False values
   - Examples: True, False

## 💡 Why is This Important?

Variables and data types are fundamental to programming:
- Store user input
- Perform calculations
- Store configuration settings
- Track application state
- And much more!
