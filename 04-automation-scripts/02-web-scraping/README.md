# 🌐 Web Scraping Scripts

## 🎯 Overview

Practical web scraping examples using BeautifulSoup and requests.

## 📝 Scripts Included

1. **basic_scraper.py** - Basic web scraping example
2. **price_scraper.py** - Scrape product prices
3. **news_scraper.py** - Extract news headlines
4. **image_downloader.py** - Download images from websites

## 📚 Requirements

```bash
pip install requests beautifulsoup4 lxml
```

## ⚠️ Important

- Always respect robots.txt
- Don't overwhelm servers with requests
- Check website terms of service
