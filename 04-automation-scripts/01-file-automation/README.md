# 📁 File Automation Scripts

## 🎯 Overview

Practical scripts for automating file operations.

## 📝 Scripts Included

1. **organize_files.py** - Organize files by extension
2. **bulk_rename.py** - Rename multiple files at once
3. **find_duplicates.py** - Find and remove duplicate files
4. **auto_backup.py** - Automated backup script
5. **compress_files.py** - Compress and decompress files

## 🚀 Usage

Each script can be run independently:

```bash
python organize_files.py
python bulk_rename.py
# etc.
```

## ⚠️ Safety

Always backup your files before running automation scripts!
