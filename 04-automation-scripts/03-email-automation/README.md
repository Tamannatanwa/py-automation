# 📧 Email Automation Scripts

## 🎯 Overview

Automate email tasks with Python.

## 📝 Scripts Included

1. **send_email.py** - Send basic emails
2. **send_with_attachment.py** - Send emails with attachments
3. **bulk_email.py** - Send emails to multiple recipients
4. **email_report.py** - Automated email reports

## 📚 Requirements

```bash
pip install secure-smtplib python-dotenv
```

## 🔐 Security

- Never hardcode passwords
- Use environment variables
- Use app-specific passwords for Gmail
