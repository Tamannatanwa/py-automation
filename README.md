## 📋 Prerequisites

Before you start, make sure you have:
- ✅ Python 3.8 or higher installed ([Download Python](https://www.python.org/downloads/))
- ✅ A code editor (VS Code, PyCharm, or any text editor)
- ✅ Basic computer literacy
- ✅ Eagerness to learn! 🎓

### Installation

```bash
# Clone this repository
git clone https://github.com/Tamannatanwa/py-automation.git
cd py-automation

# Create a virtual environment (recommended)
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate

# Install required packages
pip install -r requirements.txt
```

## 🚀 How to Use This Repository

### For Complete Beginners:
1. Start with `01-basics/01-variables-datatypes/`
2. Read the README in each folder
3. Study the `examples.py` file
4. Try the `exercises.py` yourself
5. Check your solutions against `solutions.py`
6. Move to the next topic when comfortable

### For Intermediate Learners:
1. Review basics quickly if needed
2. Focus on `02-intermediate/` section
3. Pay special attention to OOP concepts
4. Start experimenting with `04-automation-scripts/`

### For Advanced Users:
1. Jump to `03-advanced/` for advanced concepts
2. Explore automation scripts in `04-automation-scripts/`
3. Build projects from `05-real-life-projects/`
4. Customize scripts for your needs

### For Everyone:
- 💡 Each folder contains a README with concept explanations
- 📝 All code is heavily commented for clarity
- ✅ Practice exercises are included
- 🔍 Real-world use cases are demonstrated
- 📚 Refer to `resources/` for cheatsheets and best practices

## 💡 Tips for Success

1. **Practice Daily** - Even 30 minutes a day makes a difference
2. **Type Code Yourself** - Don't just copy-paste; type to learn
3. **Experiment** - Modify examples and see what happens

## ⚠️ Common Pitfalls to Avoid

- ❌ Skipping the basics - Foundation is crucial
- ❌ Not practicing enough - Reading isn't enough
- ❌ Copy-pasting without understanding
- ❌ Trying to learn everything at once
- ❌ Not reading error messages carefully
- ❌ Giving up when stuck - debugging is part of learning
